# Personal Calendar

A vanilla HTML/CSS/JavaScript personal calendar inspired by a traditional UK Monday-first calendar.

## Run it
Open `index.html` in a modern browser.

## Saving
Entries are automatically saved in the browser's localStorage under:
`bySzimiPersonalCalendar`

## Files
- `index.html` — page structure
- `style.css` — design and responsive layout
- `calendar.js` — calendar logic and localStorage persistence

## Current features
- Monday-first UK calendar layout
- Previous/next month and Today navigation
- Direct typing into each day
- Automatic local saving
- Selected-day notes panel
- Quick category actions
- Basic monthly summary
- Responsive layout
